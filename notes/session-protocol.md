# Five-turn sequence protocol

Frozen before sequence execution. Inputs: tasks/session-1.json through session-5.json. Semantic rubric: evaluation/session-answer-key.md (34 points total). The same public current snapshot is used in each independent session, without source changes.

Compare default Astra with a quality-preserving delegation policy selected from the pilot/follow-up based on lower cost or materially smaller root context. Record that selection before sequence runs. This is a targeted follow-up on the same repository, not an independent cross-project replication.

Turns cover setting inventory, workflow audit, input parsing, isolation/failure behavior, and a practical final-report recommendation. The first turn supplies an operating constraint that is not repeated in durable instructions or subsequent prompts. Report whether the fifth-turn answer respects it separately from the aggregate rubric score.

Start two fresh sessions. Alternate conditions across stages: default then treatment on odd stages, treatment then default on even stages. Resume each condition's own session and source copy between stages. Do not reuse pilot conversations. Record each turn's wall time; use the last telemetry snapshot's cumulative usage for session totals rather than adding snapshots. For per-turn usage, subtract the previous cumulative total.

As in the pilot, use the same high-reasoning settings, authentic subscription, tools, curated source, no live debate calls, isolated model workspaces, and external blind scoring. Per-turn execution cap is 900 seconds. No artificial padding. Report natural compactions, and explicitly state if none occur. A five-turn success does not prove indefinite session reliability or persistence through compaction.

Outcome: accepted work, aggregate rubric quality, late constraint retention, cumulative credit-equivalent estimate, execution time, root input-footprint trajectory, and observed worker model/task choices. Included subscription savings remain unresolved because account meter readings are not attributable to these runs alone.
