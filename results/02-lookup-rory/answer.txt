**The effective default is $5 per Claude invocation.** `--budget` overrides judge/synthesizer budgets only; it is not a total-debate spending limit.

Configuration resolution is explicit `--config` → user config → built-in lineup (`src/install.ts:28–49`; consumed at `src/index.ts:184–188`). The user config is `$XDG_CONFIG_HOME/disputatio/config.yaml`, falling back to `~/.config/disputatio/config.yaml`. Config files are selected, not merged; the example is never automatically loaded.

For Claude judges, precedence is **`--budget` → configured `maxBudgetUsd` → $5**. Claude debaters use **configured `maxBudgetUsd` → $5**. The built-in lineup has no judge (`src/index.ts:102`); supplying `--budget` does not create one.

| Execution path | Does `--budget` apply? |
|---|---|
| Normal debate | Yes, to a configured judge (`src/index.ts:340`). The same participant performs the determination and, if resolved, final synthesis (`src/debate.ts:261,275`). |
| `--continue` | Yes, to re-judging and subsequent synthesis if resolved (`src/index.ts:214,257,279`). |
| `--finalize` | Yes, to synthesis (`src/index.ts:214,240`). Continue/finalize use the built-in $5 Opus judge when config has none. |
| Debater proposals/reactions | No; participants are built without `withBudget()` (`src/index.ts:333`). |
| `--doctor` | No; configured participants and judge are built directly (`src/index.ts:196–197`). |
| `--init` | No; uses explicit config or built-in specs, seeds the $5 judge when no explicit config is supplied, and bypasses `withBudget()` (`src/index.ts:171–176`). |
